# Hospital Appointment Management System 

# Project Description
The Hospital Appointment Management System is a backend application designed to manage patients, doctors, hospital departments, and medical appointments efficiently. It allows patients to book and cancel appointments while helping hospitals manage doctors and appointment schedules.

# Project Objectives
- Register and manage patients.
- Register and manage doctors.
- Create and manage hospital departments.
- Assign doctors to departments.
- Allow patients to book and cancel appointments.
- Retrieve appointments by patient or doctor.
- Track appointment status.
- Prevent double-booking.
- Validate patient and appointment information.

# Technologies Used
- Node.js
- Express.js
- Sequelize ORM
- MySQL
- Postman (API Testing)
- Git and GitHub


# Main Features
1. Patient Management
2. Doctor Management
3. Department Management
4. Appointment Booking
5. Appointment Cancellation
6. Appointment Status Tracking
7. Double-Booking Prevention
8. Data Validation

# Appointment Status
- Pending
- Approved
- Completed
- Cancelled

# Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/afolabirichard334-sketch/Hospital-Management-system.git
```

2. Enter the project folder:

```bash
cd Hospital-Management-system
```

3. Install dependencies:

```bash
npm install
```

4. Configure your database connection and environment variables.

5. Start the server:

```bash
npm run dev
```
